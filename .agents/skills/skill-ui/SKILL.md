# Skill UI (Generative UI & Interactive Widgets)

This skill enables agents to generate and embed full interactive UI widgets with state management, live animations, and responsive controls.

## Capabilities:
- Live Interactive Control Cockpits (Maps, Sliders, Telemetry)
- Dynamic Data Visualizations (Charging Curves, Battery SoH degradation)
- Real-Time Simulation Controllers (Gezer Servis GPS, OBD-II DTC injectors)
- Theme-Adaptive Styling (Supports Host Theme Tokens)

## Component Library:
- Tailwind CSS (gStatic / CDN optimized)
- Font Awesome 6.5+ vector icons
- Chart.js / ApexCharts interactive graphs
- Leaflet geo-visualization layers
